# 승인 케스케이드 및 JIT 지식 대조 리포트 규칙

## JIT(Just-In-Time) 지식 대조 리포트 표출 의무
에이전트는 코드 수정, 스크립트 작성, 문서/아티팩트 생성 등 주요 작업을 수행할 때 반드시 `.agents/anti_patterns.json`을 사전 조회하여 관련 안티패턴을 대조해야 합니다.
대화 응답의 최상단에는 아래 포맷의 리포트를 반드시 출력해야 합니다:

```markdown
[🧠 JIT 지식 대조 리포트]

• 타겟 파일: 📖 <대상 파일 경로 또는 파일명>
• 대조 안티패턴 ID: <AP-ID-1>, <AP-ID-2>
• 사전 체크리스트:
  1. <체크 항목 1> -> ✅ 완료
  2. <체크 항목 2> -> ✅ 완료
```

## 승인 케스케이드 (Anti-Pattern 자동 축적)
- 사용자와의 대화 중 오류가 디버깅되거나 문제가 해결되었을 경우, 이를 단순 텍스트로 넘기지 않고 "승인 케스케이드" 원칙에 따라 `.agents/anti_patterns.json`에 새로운 안티패턴 객체(ID, 이름, 설명, 체크리스트, 해결책)로 즉시 등록합니다.
- 등록된 안티패턴은 이후 유사 작업 시 JIT 대조 리포트의 사전 체크리스트로 즉시 재활용됩니다.
